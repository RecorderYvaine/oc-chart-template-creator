# OC Chart Template Creator

一个面向中文视觉排版的 OC 表格制作工具。它可以在浏览器中快速制作带标题、署名、格子内容和描述文字的排版图，并导出为 PNG 图片。

## 主要功能

- 编辑主标题、全局副标题、制表人、填表人和格子内容
- 自由添加行、添加格子、删除格子，并支持单行铺满宽度
- 为每个格子设置标题、小字和多行补充描述
- 调整字体、字号、颜色、间距、边框、背景和画布留白
- 支持思源宋体、思源黑体、汇文明朝体、齐伋体等中文字体
- 支持透明格子、格子填充开关、边框显示开关
- 支持画布缩放、预览生成和 PNG 下载
- 自动保存当前草稿，刷新页面后继续编辑
- 支持撤销和重做，常规编辑区域可使用 `Cmd+Z` 和 `Cmd+Shift+Z`

## 字体加载

选择任意字体时，如果对应字体还没有加载完成，界面会显示字体加载提示。导出图片前会等待浏览器字体加载完成，尽量保证导出的 PNG 与画布预览一致。

## 适合用途

- OC 设定表
- 角色关系/资料卡
- 多格排版模板
- 中文标题海报和表格式视觉素材
